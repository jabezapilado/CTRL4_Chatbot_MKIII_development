# Historical Documentation Archive

These documents preserve MK II planning, model, dataset, design, ethics, and
Sprint 3 audit material for thesis provenance. They are not current
implementation specifications and intentionally retain their historical
terminology.

For the implemented CTRL4 Chatbot MK III system, use the current-reference
documents in the parent `docs/` directory, especially the project architecture,
API reference, security architecture, deployment guide, installation guide,
role guides, and project context.
